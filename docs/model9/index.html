About this model

XGBoost multiclass classification retrained with 9 predictors. The 3,083-record dataset was split into stratified training (80%) and test (20%) sets, with random seed 20260925.

Predictors: Glucose, PaCO₂, Albumin, Platelet, Leukocyte, Age, BMI, MAP and Sex. Sex is coded 0 = male and 1 = female.

The outcome is coded 1 = α, 2 = β, 3 = γ, and 4 = δ. These figures describe internal testing; external validation has not been provided.

Input units follow the supplied calculator specification. For research evaluation; clinical use requires further validation.

Calculations run on your device. Entered values are not sent to a prediction server or saved by this app.
